# Native games

| Game | Mission |
| --- | --- |
| [Neon Maze](Pacman/README.md) | Collect dots and avoid ghosts in a neon maze. |
| [Equalizarr](Equalizarr/README.md) | Break through 50 levels with eight power-ups; complete ten levels to rescue Yuki. |
| [Bass Rocks](Asteroids/README.md) | Clear asteroid waves, dodge UFOs and reach wave 4 to rescue Peach. |
| [Basslines](Basslines/README.md) | Outlast three neon riders and win all eight arenas to rescue Cookie. |
| [Drop Defense](Space%20Invaders/README.md) | Defend against advancing formations and reach wave 4 to rescue Mochi. |
| [DJ Wars](DJ%20Wars/README.md) | Bring the rescued crew to a 5-versus-5 nightclub showdown. |

The games share the RX3 launcher, graphics theme and audio controls. Scores and
rescue progress are session-only by default; persistent saves are optional in
the installer. DJ Wars opens after all four cats have been rescued.

Additional source folders include the experimental [WarMUX](WarMUX/README.md)
port and the [Sync Button Cat](Sync%20Button%20Cat/README.md) placeholder.
These are not part of the main rescue campaign.
