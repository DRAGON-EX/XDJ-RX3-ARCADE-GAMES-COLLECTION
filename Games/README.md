# Games

- [Native](Native/README.md): games built directly into the RX3 application.
- [EMU / NES](EMU/NES/README.md): the NES frontend and per-game RX3 adaptations.

Commercial ROMs are supplied locally by the user and are never committed here.
Shared launcher, display, audio and device code remains in `../native/`.
Build tools and regression tests remain in the root `tools/` and `tests/` folders.
