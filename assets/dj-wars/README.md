# DJ Master artwork

`guetta-chibi-v1.png` was generated with the built-in Imagegen tool for this project.
`tools/build_dj_master.py` extracts the four poses into a 67,072-byte immutable
indexed atlas shared by native RX3 and browser renderers.

## Generation prompt

Create a high-quality pixel-art chibi caricature of David Guetta for a playful
cat-rescue arcade game, on a transparent background. Four full-body poses in a
2 by 2 sheet: confident idle, comedic facepalm, turquoise DJ baton aimed right,
and hands-up celebration. Oversized head about half the total height, small
body and short limbs, expressive kind brown eyes, sandy blond swept-back
hair, short beard, black T-shirt/trousers, white sneakers, turquoise headphones.
Detailed crisp pixel clusters, soft limited-color shading, dark warm outlines;
match the shaded 16-bit chibi cats in a cozy pixel café. Same proportions and
feet baseline for all poses. Whole figure visible, no labels, text, frames,
ground shadows or background. Readable at 128 pixels high.
